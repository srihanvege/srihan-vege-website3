# Srihan Vege — Portfolio

Personal portfolio site for Srihan Vege, CS and Mathematics student at Purdue University and ML researcher.

Built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

### Stack

- React 18 + TypeScript
- Vite (build tooling)
- Tailwind CSS (utility styling)
- Framer Motion (animations and scroll effects)
- Lucide React (icons)
- Fonts: Archivo (display), Space Grotesk (body), JetBrains Mono (labels)

### Features

- Full-screen dark hero with animated gradient orbs and grain texture
- Parallax scroll on hero text and photo
- Scroll progress bar
- Scroll-triggered section reveals with staggered animations
- Timeline-style experience section
- Continuous skills marquee strip
- Project cards with hover glow
- Dark-only design (OLED-friendly)

### Dev

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```
